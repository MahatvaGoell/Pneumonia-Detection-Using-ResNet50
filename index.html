Pneumonia detection from chest X-rays.

An AI-assisted screening project that applies transfer learning with ResNet50 to classify chest X-ray images as normal or pneumonia.

AI-assisted chest X-ray screening

PROJECT OVERVIEW

A clear workflow for image-based screening.

The project combines a ResNet50 classifier with an easy-to-use web interface, making the model’s output simple to explore and present.

01 / INPUT

Upload an X-ray

A chest X-ray image is prepared for the model at a consistent input size.

02 / ANALYZE

Run ResNet50

The trained binary classifier estimates whether pneumonia-related patterns are present.

03 / EXPLAIN

Review the result

The interface presents the predicted class and confidence, with Grad-CAM support for visual explanation.

WHAT MAKES IT USEFUL

Built around practical AI concepts.

01

Transfer learning

ResNet50 provides a strong visual feature-extraction foundation for chest X-ray classification.

02

Confidence score

Predictions are paired with a model confidence value for easier interpretation.

03

Explainable AI

Grad-CAM can highlight image regions that most influenced the model’s decision.

Technology stack

Python-based computer vision and deep learning, presented through a simple interactive interface.
